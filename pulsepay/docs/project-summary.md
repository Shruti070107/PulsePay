# PulsePay — Upgraded Project Summary

PulsePay is an Evidence-Driven AI Payment Incident Intelligence Platform that reconstructs ambiguous transaction states, compiles structured evidence checklists, isolates statistical outliers using ML, and leverages AI for safe, advisory root cause diagnostics.

## Key Upgrades (Evidence-Driven Upgrade)
- **Blast Radius Indicators**: Grids calculating orders, merchant counts, durations, and failure rates.
- **Signal Fusion**: Matches deterministic checks with ML Isolation Forest outlier scores.
- **Chronological Timeline Delay Traces**: Compares logical timestamps with arrival logs to highlight delays and out-of-order logs.
- **Confidence Breakdown Math**: Explains confidence score through deterministic weight credits (+25 state mismatch, +20 webhook drops).
- **Causal Graph**: Monaco border boxes tracing sequence transitions.
- **Operator checklist**: Persisted check tasks allowing state tracking.
- **One-Click Demo Mode**: Seeding pipeline automation.

## Core Innovations
- Deterministic state engines act as source of truth.
- Leader-Follower groupings cluster signals.
- Isolation Forest microservice acts as unsupervised anomaly detector.
- Sandbox guardrails keep AI investigator strictly advisory.
